## 为什么需要公网访问？

后端通常运行在你的服务器上，前端在你的个人电脑上。如果服务器和电脑在同一个局域网内（比如同一个路由器下），直接填内网 IP 就能连上。

但如果服务器在家里，你在外面（或者服务器在机房、云服务器上），就需要让后端能被公网访问到。

以下是几种常见的方案，从简单到复杂排列。

---

## 方案一：端口转发（适合有公网 IP）

如果你的网络运营商给你分配了公网 IP（无论是静态还是动态），这是最直接的方式。

### 操作步骤

1. **进入路由器管理界面**（通常是 `192.168.1.1` 或 `192.168.0.1`）
2. 找到 **「端口转发」** 或 **「虚拟服务器」** 功能
3. 添加一条规则：
   - 外部端口：`20000`（或你设置的后端端口）
   - 内部 IP：运行后端的服务器内网地址（如 `192.168.1.100`）
   - 内部端口：`20000`
   - 协议：`TCP`
4. 保存并应用

之后，前端填写你路由器的公网 IP 即可连接。

> 如果你的公网 IP 是动态的（每次重启路由器会变），可以配合 **DDNS（动态域名解析）** 服务，用域名代替 IP 地址。

### 注意事项

- 某些运营商（如部分移动、小区宽带）可能不提供公网 IP，需要打电话申请
- 开放端口到公网意味着任何人都有可能尝试连接到你的后端，**务必设置强密码**

---

## 方案二：内网穿透（适合没有公网 IP）

如果你的网络没有公网 IP，或者不想折腾路由器设置，可以使用内网穿透工具。

原理：你的服务器主动连接到一个中间服务器（有公网 IP 的），前端也连接同一个中间服务器，双方通过中间服务器中转数据。

### 推荐的内网穿透工具

| 工具 | 特点 | 价格 |
|---|---|---|
| **SakuraFrp** | 国内节点多，速度快，有免费隧道，配置简单 | 免费/付费 |
| **OpenFrp** | 国内 Frp 服务商，有免费节点，配置方便 | 免费/付费 |
| **Tailscale** | 基于 WireGuard 的虚拟组网，配置极简，设备之间直连 | 个人免费 |
| **ZeroTier** | 类似 Tailscale，功能强大，支持自定义网络 | 个人免费 |
| **FRP** | 开源老牌工具，需要自己有一台有公网 IP 的服务器做中转 | 需自备服务器 |
| **Ngrok** | 国外知名工具，免费版有带宽和连接数限制 | 免费/付费 |

### 简单示例：使用 SakuraFrp

1. 去 [SakuraFrp 官网](https://www.natfrp.com/) 注册账号
2. 下载客户端到你的服务器上
3. 创建一个隧道：
   - 本地地址：`127.0.0.1`
   - 本地端口：`20000`（后端端口）
   - 远程端口：随便选一个（比如 `20000`）
4. 启动隧道，会得到一个公网地址，例如 `xxx.natfrp.com:20000`
5. 前端填写这个地址和端口即可连接

### 简单示例：使用 Tailscale

1. 在你的服务器和你的个人电脑上都安装 [Tailscale](https://tailscale.com/)
2. 两部设备登录同一个账号
3. 它们会自动组建一个虚拟局域网，分配一个 `100.x.x.x` 的虚拟 IP
4. 前端填写服务器的 Tailscale 虚拟 IP 和后端端口即可连接

Tailscale 的优势是**不需要额外配置端口转发**，而且连接是端到端加密的，数据不走第三方服务器（大多数情况下是直连）。

---

## 方案三：云服务器

如果你的后端直接运行在云服务器上（比如阿里云、腾讯云、华为云、AWS 等），通常云服务器本身就有公网 IP。你需要做的是：

1. **在云服务器的防火墙/安全组中放行后端端口**（默认 `20000`，TCP）
2. 直接使用云服务器的公网 IP 或域名连接

> 这是最省心的方案，适合已经有云服务器的用户。

---

## 安全提醒

无论使用哪种方案将后端暴露到公网，请注意：

- ⚠️ **设置一个足够复杂的访问密钥**（至少 16 位，包含大小写字母和数字）
- ⚠️ **不要使用默认端口 `20000`**，建议换一个不常用的高位端口
- ⚠️ **首次连接时务必核对 RSA 公钥指纹**，防止中间人攻击
- ⚠️ 如果使用端口转发，建议配合**防火墙**限制可访问的 IP 范围

> 如果只是你自己用，Tailscale 或 ZeroTier 这类虚拟组网方案是最推荐的选择——不需要开放任何端口到公网，安全性最高。
