## 这是什么？

**PMCSsE**（Prime Minecraft Servers Engine）是一套帮你远程管理 Minecraft 服务端的工具。

想象一下：你的 Minecraft 服务器放在一台远程机器上，每次要开关服、输指令都得通过远程桌面或者 SSH 连上去敲命令，是不是很麻烦？PMCSsE 就是为了解决这个痛点而生的——它给你一个**图形化的遥控器**，让你坐在自己电脑前就能搞定所有事。

---

## 前后端分离是什么意思？

PMCSsE 由**两个独立的部分**组成，各司其职：

- **后端（Backend）** → 放在你的服务器上默默运行，负责实际管理 Minecraft 服务端
- **前端（Frontend）** → 装在你自己的电脑或手机上，用来远程遥控后端

用个比喻来说：
> 后端是**舞台上的演员**，前端是**导演手里的监视器**。导演不用亲自上台，也能知道台上发生了什么、随时下达指令。

这样做的好处是：
- 服务器只需要专心跑 Minecraft，不用分精力去渲染网页界面
- 前后端之间的通信经过加密，别人截获了也看不懂
- 你可以同时管理**多个** Minecraft 服务端实例
- 扩展性强，支持插件，可以实现更多自定义功能

## 当前版本（v1.0.4）能做什么？
---
| 能做啥 | 说明 |
|---|---|
| 🔗 **远程连接后端** | 输入服务器 IP 和访问密钥，就能安全地连上后端 |
| 📋 **管理多个服务端** | 在本软件中添加、加载、删除多个 Minecraft 服务端实例 |
| ▶️ **一键启停服务端** | 启动服务端、优雅关闭（发送 stop 命令）、或者强制终止 |
| ⌨️ **远程发命令** | 就像在游戏控制台里打字一样，远程向服务端发送指令 |
| 📜 **查看服务端日志** | 实时查看服务端输出的日志，还能往上翻看历史记录 |
| ⚙️ **修改配置** | 改服务端目录、Java 路径、启动参数等 |
| 🔌 **支持插件扩展** | 把 DLL 文件丢进插件文件夹，后端启动时自动加载，可以实现更多功能 |

> 以上是目前版本实际可用的功能。更多功能（如自动部署服务端、配置文件编辑、命令补全、备份管理等）正在开发中，后续版本会逐步开放。

## 那么，如何开始使用？

建议按以下顺序阅读本手册：

1. **项目架构概览** — 先了解整体是怎么回事
2. **后端配置与启动** — 在服务器上把后端跑起来
3. **前端的安装与使用** — 在自己电脑上装好前端并连上后端
4. **服务端管理器的使用** — 学会添加、启动、管理你的 Minecraft 服务端
