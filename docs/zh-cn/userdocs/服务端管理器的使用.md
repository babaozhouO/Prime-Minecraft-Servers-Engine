## 概览

成功连接后端后，管理 Minecraft 服务端的入口主要在**两个标签页**中：

| 标签页 | 作用 |
|---|---|
| **所有管理器** | 查看所有已保存的管理器配置，可以新建、加载、删除 |
| **运行中的管理器** | 查看已加载到内存中的实例及其运行状态，可以打开控制台进行操作 |

简单来说：
> 「所有管理器」就像你的**存档列表**，里面放着各个服务端的配置信息。
> 「运行中的管理器」就像**当前打开的存档**，只有加载到这里才能开始操作。

---

## 「所有管理器」标签页

连接后端后，点击顶部的 **「所有管理器」** 标签页，你会看到：

- **左侧列表**：显示所有已保存的管理器配置（每条显示：服务端名称、ID、类型）
- **右侧操作按钮**：

| 按钮 | 作用 |
|---|---|
| **刷新** | 从后端重新拉取最新的配置列表 |
| **新建** | 创建一个新的空配置（后端自动分配 ID） |
| **启动** | 将选中的配置加载到「运行中的管理器」 |
| **停止** | 从「运行中的管理器」中卸载选中的实例 |
| **删除** | 从当前列表中移除选中的配置（**需点击「保存」才会持久化**） |
| **保存** | 将当前所有配置持久化保存到后端 |

### 新建管理器

1. 点击 **「新建」** 按钮
2. 后端会自动分配一个三位数的 ID（如 `001`、`002`）
3. 新建的配置会出现在列表中，但各项内容还是空的
4. 后续需要在管理器的**设置页面**中填写具体信息（见下文）

### 加载管理器

1. 在列表中选中一个配置（点击它，背景会高亮）
2. 点击 **「启动」** 按钮
3. 该管理器会出现在 **「运行中的管理器」** 标签页中

> 加载成功后，就可以在「运行中的管理器」中打开它的控制台了。

---

## 「运行中的管理器」标签页

点击顶部的 **「运行中的管理器」** 标签页，你会看到：

- **左侧列表**：显示所有已加载的管理器（每条显示：服务端名称、ID、类型、**运行状态**）
  - 运行状态显示 **「运行中」** 或 **「已停止」**
- **右侧操作按钮**：

| 按钮 | 作用 |
|---|---|
| **刷新** | 从后端重新拉取最新的运行状态 |
| **打开** | 打开选中管理器的详情面板（控制台 / 设置） |
| **保存** | 将当前配置持久化保存到后端 |

---

## 打开管理器——详情面板

在 **「运行中的管理器」** 列表中选中一个管理器，点击 **「打开」**，界面会覆盖一个**详情面板**。

这个面板的右侧有一个**抽屉式导航栏**，里面有多个功能页面可供切换：

| 页面 | 功能 |
|---|---|
| **控制台** | **核心操作区**——启停服务端、发命令、看日志 |
| **备份** | 备份功能（入口已存在，功能待完善） |
| **互联** |（待开发） |
| **文件管理** |（待开发） |
| **设置** | 编辑管理器的各项配置 |

> 点击抽屉导航底部的 **「返回」** 按钮，可以关闭详情面板，回到主界面。

### ① 控制台页面

控制台是管理器的**核心**，你可以在这里完成所有日常操作。

#### 页面布局

```
┌─────────────────────────────────────────────────────┐
│  服务端名称                    [日志轮询间隔滑块]   │
├─────────────────────────────────────────────────────┤
│                                                     │
│             日志展示区（带行号）                      │
│                                                     │
├─────────────────────────────────────────────────────┤
│  [命令输入框...]  [发送] [旧日志] [启动] [关闭] [终止]│
└─────────────────────────────────────────────────────┘
```

#### 启停服务端

底部四个按钮从左到右：

| 按钮 | 作用 |
|---|---|
| **启动** | 启动 Minecraft 服务端（需先配置好 Java 路径和启动参数） |
| **关闭** | 优雅关闭——向服务端发送 `stop` 命令，让服务端自己保存数据后退出 |
| **终止** | 强制终止——直接杀死服务端进程，**可能损坏数据**，仅在服务端卡死时使用 |
| **旧日志** | 加载更早的历史日志 |

> 建议每次都用 **「关闭」** 来停止服务端，这样能保证地图数据安全保存。

#### 发送命令

- 在底部的输入框中输入命令（**不需要**加斜杠 `/`）
- 按回车或点击发送按钮，命令就会被发送到 Minecraft 服务端
- 输入框支持**自动补全**（此功能尚未完成，暂不可用）

#### 查看日志

- 日志展示区会**实时显示**服务端的输出
- 行号会自增编号
- 点击 **「旧日志」** 按钮可以翻看历史记录

### ② 设置页面

在右侧抽屉导航中点击 **「设置」**，可以修改当前管理器的各项配置。

#### 可修改的配置项

| 配置项 | 说明 |
|---|---|
| **服务器名称** | 给你自己看的名字，方便区分不同服务端 |
| **服务端类型** | 选择你的 Minecraft 服务端种类。如果列表中没有你的服务端，可以选择它的**上游**（例如 Leaves 选 Paper）。实在找不到就选 **Vanilla（原版）**。不同选项的区别仅在于支持的功能多少，不影响服务端正常运行 |
| **服务端根目录** | Minecraft 服务端文件所在的文件夹（绝对路径） |
| **Java 路径** | Java 可执行文件的路径（如 `/usr/bin/java` 或 `C:\Program Files\Java\bin\java.exe`） |
| **启动参数** | 启动 Java 时的参数（包括内存分配、核心 jar 等）。已有启动参数生成器功能，但目前尚无入口使用 ⏳ |

#### 修改步骤

1. 点击 **「修改配置」** 按钮——此时各输入框变为可编辑状态
2. 修改你想要改的配置项
3. 点击 **「提交配置」** 按钮——修改后的配置会发送到后端并保存

> **注意**：启动参数如果包含高危项（如某些危险参数），后端会自动拒绝并给出提示。

## 停止 vs 删除

| 操作 | 位置 | 效果 |
|---|---|---|
| **停止** | 「所有管理器」→ 选中 → 点击「停止」 | 从「运行中」列表移除，但配置还在「所有管理器」中，下次可以重新加载 |
| **删除** | 「所有管理器」→ 选中 → 点击「删除」 | 从当前列表中移除，但只要没点「保存」按钮，配置就不会写入后端。如果误删了，不保存并**重启后端**即可从文件重新读取原始配置 |

> 暂时不用的管理器用 **「停止」** 就行，只有确定不再需要时才用 **「删除」**。
