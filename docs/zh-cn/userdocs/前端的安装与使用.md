## 运行环境

- **Windows**：需要安装 .NET 10 Desktop Runtime
  - 如果你已经按照"后端配置与启动"篇装过了，就不用再装
  - 还没装的：[下载 .NET 10 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- **Linux 桌面**：同样需要 .NET 10 Runtime，以及桌面环境（GNOME / KDE 等）
- **Android**：直接安装 APK 即可，无需额外环境

> 💡 如果双击没反应，请检查 .NET 运行库是否安装成功。可以在命令行输入 `dotnet --info` 查看已安装的版本。

## 启动前端

### Windows

进入 `PMCSsE_Frontend_AvaloniaUI.Desktop` 文件夹，**双击** `PMCSsE_Frontend_AvaloniaUI.Desktop.exe` 即可启动。

你也可以给 exe 创建快捷方式：右键 → **「发送到」→「桌面快捷方式」**，或右键 → **「固定到开始屏幕」**，以后双击图标就能打开。

### Linux

在终端中运行：
```bash
cd PMCSsE_Frontend_AvaloniaUI.Desktop
./PMCSsE_Frontend_AvaloniaUI.Desktop
```

也可以创建桌面快捷方式（`.desktop` 文件），方便下次直接双击打开。

### Android

直接安装 APK 文件，安装后从应用列表中打开。

> iOS 版：项目已包含 iOS 工程，但因缺少苹果开发者账号，暂无法发布。

## 连接后端

打开前端后，你会看到如下界面（以桌面版为例）：

### 第一步：添加后端连接

在默认的"连接"页面中，选择 **「添加」** 标签页，填写以下信息：

| 填写项 | 说明 |
|---|---|
| **主机名/IP** | 你的服务器 IP 地址或域名（如 `192.168.1.100` 或 `mc.example.com`） |
| **端口号** | 后端设置的端口号（默认 `20000`） |
| **访问密钥** | 后端首次配置时设置的密钥（可选，不填则连接时需要手动输入） |

填写完成后，点击 **「添加」** 按钮。

> ⚠️ **访问密钥框如果有内容，添加后会自动保存到本地配置文件中——且是明文存储。** 下次连接时可直接使用，但任何能访问你电脑的人都能看到它。如果不填，连接时会弹出输入框让你手动输入，更加安全。请根据情况权衡便利与安全。

### 第二步：从后端列表连接

添加成功后，点击 **「后端列表」** 标签页。

你会看到刚刚添加的后端记录，每条记录有三个按钮：

| 按钮 | 作用 |
|---|---|
| 🔗 **连接** | 连接到这个后端 |
| ✏️ **修改密钥** | 修改当前记录的访问密钥 |
| 🗑️ **删除** | 从列表中移除这条记录 |

点击 **「连接」** 按钮开始连接后端。

### 第三步：验证服务器身份（首次连接）

第一次连接到一个后端时，前端会显示一串 RSA 公钥指纹，像这样：

```
正在验证服务器的身份...
请确认以下指纹是否匹配：
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```

这是为了防止"中间人攻击"——简单说就是防止有人冒充你的服务器。

你需要做的是：
1. 去后端控制台找到对应的指纹（后端启动时会打印出来），对比是否一致
2. 如果一致，点击 **「RSA公钥一致」**
3. 如果不一致，**切勿点击确认！这可能是中间人攻击**——说明有人可能在冒充你的服务器，请立即检查网络环境

> 同一个后端的指纹只需要验证一次，之后会自动记住。

### 第四步：输入访问密钥

验证通过后，前端会弹出密码输入框。输入你设置的后端访问密钥，点击 **「确定」**。

如果密钥正确，前端就会成功连上后端，你会看到界面发生变化——连接状态图标变为**已连接**。

## 连接成功后的界面

连接成功后，你会看到主界面有六个顶部选项卡：

| 选项卡 | 作用 |
|---|---|
| 🔗 **连接** | 管理后端连接（添加/断开/查看连接日志） |
| 📦 **所有管理器** | 查看所有已保存的管理器配置，可新建/加载/删除 |
| ⚡ **运行中的管理器** | 查看已加载的实例及其运行状态，可打开控制台 |
| 🧰 **工具箱** | （待开发） |
| ⚙️ **设置** | （待开发） |
| ℹ️ **关于** | 软件信息、更新日志、引用清单 |

> 主要操作集中在 **「所有管理器」** 和 **「运行中的管理器」** 这两个标签页。接下来你会在 **「服务端管理器的使用」** 中学习具体怎么操作。

## 如何断开连接

在 **「连接」** 选项卡中，点击 **「断开」** 按钮即可断开与后端的连接。断开后之前获取的所有数据会被清空，重新连接后会重新加载。
