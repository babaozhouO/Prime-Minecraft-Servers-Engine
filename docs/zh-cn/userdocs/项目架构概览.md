## 整体结构

PMCSsE 由**三个核心部分**组成，它们各司其职、协同工作：

```
┌─────────────────┐    加密通信     ┌──────────────────────┐         ┌──────────────────┐
│                 │  ◄──────────►   │                      │  管理    │                  │
│   前端           │                 │   后端                │────────►│  Minecraft 服务端 │
│   (你电脑上)     │                 │   (服务器上)          │         │  (一个或多个)     │
│                 │                 │                      │         │                  │
└─────────────────┘                 └──────────────────────┘         └──────────────────┘
```

一句话概括：
> **前端**是你手里的遥控器，**后端**是放在服务器上的管家，管家负责看管一个或多个 **Minecraft 服务端**，遥控器和管家之间通过加密电话线联系。

---

## 三个组成部分

### 1. 后端（PMCSsE_Backend）

这是整个软件的核心，它是一**个后台程序**，需要长时间运行在你的服务器上。

后端负责的活：
- 等待前端连接过来
- 根据前端的指令去**启动/停止** Minecraft 服务端
- 把 Minecraft 服务端输出的**日志**转发给前端
- 帮你**转发命令**给 Minecraft 服务端（就像你在游戏里按 T 打开对话框输入指令一样）
- 从**插件文件夹**里自动加载插件

后端本身没有图形界面，就是一个控制台窗口（或者后台静默运行），所有操作都通过前端来远程控制。

### 2. 前端（PMCSsE_Frontend_AvaloniaUI）

这是你直接操作的图形界面软件，装在自己电脑或手机上。所有平台的操作逻辑和体验完全一致，只是性能有所区别：

| 平台 | 说明 |
|---|---|
| **Windows / Linux / macOS** | 桌面版 |
| **Android** | 手机或平板也能用 |
| **iOS** | ⏳ 项目已包含 iOS 工程，但因缺少苹果开发者账号，暂无法发布 |

前端做的事情：
- 提供**连接界面**：输入服务器 IP、端口和访问密钥，连上后端
- 提供**管理界面**：添加/删除 Minecraft 服务端管理器
- 提供**控制台界面**：启停服务端、发命令、看日志
- 提供**配置界面**：修改 Java 路径、启动参数等

### 3. 通信库（PMCSsE_Communicator）

这个部分你看不到，也碰不到，但它是最重要的"中间人"。它是一个代码库，前后端都引用了它，负责：

- **建立安全连接**：确保只有知道密钥的人能连上你的后端
- **加密传输**：所有在前后端之间传输的数据都经过加密
- **定义"语言"**：规定了前后端之间能说哪些话（比如"启动服务端"、"获取日志"等）

---

## 通信是安全的

前端和后端之间的所有通信都是加密的。简单来说就像这样：

1. **确认身份**：后端先亮出自己的"身份证"（一串数字指纹），前端确认是你认识的那个服务器
2. **交换钥匙**：双方协商出一把只有他俩知道的临时钥匙
3. **上锁通信**：之后所有对话都用这把钥匙加密，即使有人在中间偷听，看到的也只是一堆乱码

所以你不用担心在公共网络（比如公司 WiFi、手机流量）上使用时被人窃听。

---

## 插件是怎么回事

PMCSsE 支持**插件扩展**。你可以把插件想象成游戏机上的**卡带**：

- 后端像一台游戏主机，只提供基础功能
- 插件像游戏卡带，插上去就能增加新玩法
- 插件是 `.dll` 文件，丢到后端的 `plugins` 文件夹里即可

举个例子：官方提供了一个示例插件，它能在启动原版（Vanilla）服务端时自动帮你获取版本号。

---

## 小结

| 组成部分 | 在哪运行 | 干什么 |
|---|---|---|
| **后端** | 你的服务器上 | 实际管理 Minecraft 服务端进程 |
| **前端** | 你用的电脑/手机/浏览器上 | 提供图形界面让你远程操作 |
| **通信库** | 内置于前后端中 | 负责加密通信、定义交流规则 |

> **接下来你会学到**：
> 1. 怎么在服务器上把后端跑起来 → **后端配置与启动**
> 2. 怎么在自己电脑上装前端并连上后端 → **前端的安装与使用**
> 3. 怎么添加和管理 Minecraft 服务端 → **服务端管理器的使用**
