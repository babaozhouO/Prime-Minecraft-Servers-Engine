# Prime-Minecraft-Servers-Engine_FrontendAndBackendCommunicator
A library specifically designed for front-end and back-end communication of PMCSsE.  
一个专门用于PMCSsE前后端通信的库。

## 特性

- 安全，使用RSA和AES加密
- 使用Tcp协议，保证数据无误传输
- 支持多客户端并发连接
