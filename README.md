## 应用介绍
- 一套用于管理多个Minecraft服务端的软件，旨在为各种操作提供便捷的界面和多种运维功能。
### 🚀 功能开发进度
| 基本功能：| 进度 |
|------------------------------------------------------------|-------|
|   1.前后端通信                                               | 80%  |
|   2.自动下载 + 部署各种类型的服务端                            | 0%  |
|   3.托管(多个)服务端，快速启停服务端、查看服务端日志、命令输入   | ✔  |
|   4.监控服务端资源占用（CPU、内存、IO等）                      | 0%  |
|   5.实时查看玩家列表                                          | 0%  |
|   6.快速打开如[服务端目录]、[模组/插件文件夹]等文件夹功能        | 30%  |

| 高级功能：| 进度 |
|------------------------------------------------------------------------|-------|
|   1.发送文件至SFTP文件服务器                                             | 90%  |
|   2.服内外互联系统（类似于群服互联但群为自行实现的网页，无需QQ机器人，稳定易用） | √ |
|   3.基于智能学习的自动命令提示（支持TAB自动补全）                           | 0%  |
|   4.智能服务端类型检测（保留手动指定选项）                                 | 0%  |
|   5.提供不同类型服务端的特殊命令免学习支持                                  | 0%  |
|   6.基于服务端类型的快捷配置文件编辑功能 + 配置项中文解释                    | 0%  |
|   7.全量备份                                                             | √ |
|   8.文件级增量备份                                                        | 0%  |
|   9.块级增量备份                                                           | 0%  |

· 注：高级功能1与7，8，9可联动使用
