# 开始使用服务端管理器
在上一部分已经介绍了如何增添和删除“MC服务端管理器”。  
接下来是介绍如何开启并使用一个MC服务端管理器  
## **MC服务端管理器！启动！**

如下图：  
![打开服务端管理器](如何打开服务端管理器.png "照着图片操作即可打开MC服务端管理器") 

* Tips：
* 按住“CTRL”点击选择了多个时只会打开第一个选择的
* 按住“CTRL”再次点击已选择的可以取消选择
 
然后你就会看到以下画面：  
![服务端管理器画面](服务端管理器画面.png "你会看到的画面")  

## **切换页面**
如图，点击其中一个即可切换到对应的页面
![页面切换按钮](页面切换按钮.png "点击其中一个即可切换到对应的页面")

## **MC服务端控制台页面**

MC服务端控制台页面是管理器的**核心**，你可以在这里启停服务端，查看日志，输入命令，使用各种功能。
#### **服务端操作**

如下图，四个按钮从左到右分别对应了  

1. “启动服务端”
2. “关闭服务端”
3. “终止服务端”
4. “打开服务端管理器的设置页面”

![服务端操作区](服务端操作.png "在这里快速启停服务端")

#### **控制日志的显示**
如下图，具体功能**试试**就知道了  
![管理日志如何显示图片](管理日志如何显示.png "别光看啊，快去试试")

* Tips：
* “显示调试日志”被勾选后可能会输出**巨量**日志
* “显示调试日志”被勾选后**才会**开始在控制台追加调试日志
