## 简介

* PMCSsE是一套多功能的服务端管理软件，不止是一个面板，它旨在方便腐竹及管理员对（多个）服务端的配置和维护
* 结构上前后端分离，前后端分别为独立软件，不同于其它管理面板的网页操作
* 好处：服务器端不需要发送网页、处理表单，而是专注于管理服务端，减少资源消耗，因为后端仅需向前端发送数据
* 使用更高效，更底层，更迅捷的底层tcp，同样降低了资源消耗，二进制传输还能节省腐竹们的服务器流量、带宽
* 扩展性强，支持插件，无限可能。

## 功能介绍及开发进度
---
| 功能 | 完成度 | 介绍 |
| ----- | :------: | ----- |
| 自动安装部署MC服务端 | 未开始 | 类型和版本的选择，自动下载并初始化，同意服务端的EULA等 |
| 自动检测已有MC服务端的类型 | 40% | 在服务器管理器添加窗口处指定一个非空目录即可开始检测 |
| 生成启动参数 | 已完成 | 根据内存，核心文件名称生成参数，在内存分配过多过少时有相关提示 |
| 托管MC服务端 | 60% | 启停服务端，显示服务端日志，实时查看玩家列表，CPU、内存占用等数据 |
| 快捷打开文件夹 | 10% | 根据服务端类型，打开诸如服务端目录，存档文件夹等文件夹 |
| 配置文件编辑 | 未开始 | 根据服务端类型和版本，提供各种配置文件的查看和编辑功能（带中文注释） |
| 命令自动补全功能 | 未开始 | 根据用户命令输入、自动执行help命令查询等方式自动学习命令，对于不同类型服务端提供免学习补全 |
| 备份 | 33% | 三种备份方式：全量备份、文件级增量备份、块级增量备份。三种触发方式：指定间隔时长循环运行（例如隔3小时备份一次）、指定间隔天数和运行时间点循环运行（例如在两天后的凌晨2时备份）、手动触发 |
| 备份后上传文件至远程服务器 | 已完成 | 自动在备份完成后使用SFTP协议上传文件至远程服务器（带断点续传功能） |
| 备份管理 | 未开始 | 查看、合并、发送、回档历史备份 |
| 实时服内外通信与管理 | 80% | 后端会以指定的地址和端口启动一个Web服务器（网页）和Websocket服务器（与网页通信），包含了聊天，在线玩家列表，性能监视，后台日志查看，发送命令等功能 |
